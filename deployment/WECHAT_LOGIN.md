# GXNU校跑：微信登录、退出与账户注销

更新：2026-09-23。AppID 为 `wx3d8dc6fb0e764ec7`，项目基础库为 `3.17.1`。本文描述当前代码及部署要求；本地通过不代表云端已部署或真机已验收。

## 登录与个人资料

1. 打开登录页只显示登录入口，不自动创建账号、恢复资料或撤销注销。
2. 点击“点击微信登录”，在同一弹层选择头像并填写微信昵称；原生控件为 `chooseAvatar` 与 `input type="nickname"`。两项均填好后点击“确认并继续”。取消弹层不会发起身份登录。
3. 使用云开发可信微信身份创建／恢复账号，取得服务端会话，保存头像和昵称，自动进入“个人资料”。已有完整资料的账号也经过该入口进入个人资料。原业务页面地址会保留，资料保存后继续返回。
4. 个人资料中的联系资料始终展开，没有“收起／编辑联系资料”按钮。页面统一用“保存资料”，下方可退出登录或注销账户。新账号即使尚未补齐联系资料，也可进入“我的”管理账号。

微信目前不支持通过旧式的一次授权弹窗自动读取真实头像和昵称。这里使用官方原生填写控件：头像由用户选择，昵称输入时可使用微信昵称候选。保存读取 form 提交的最终昵称，不能用旧输入缓存覆盖。控件不可用时保留普通输入、相册／相机选择。官方规则见 [获取头像昵称](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/userProfile.html)，最终原生行为须在真机验证。

身份登录成功、头像上传或保存失败时，弹层保留已选资料并显示错误；主动重试复用当前有效身份会话，不重复建号。退出、重新登录或会话失效后，旧资料请求、上传回包和业务自动重试不能写入新会话。

默认不调用手机号识别。联系电话由用户填写；保持旧验证号码时保留标记，更改号码后清除微信验证标记，并检查学校内号码归属。发布／接单仍需满足昵称、头像、联系电话、性别、学院、专业、校区及审核要求。待审核、审核拒绝和停用账号不能通过再次登录绕过业务限制。文字检查说明见 [CONTENT_AUDIT.md](CONTENT_AUDIT.md)。

独立手动注册和授权失败后自动转手动注册已移除；资料表单只能更新通过微信登录建立的账号，不能给游客建号。

## 退出登录

“我的”和“个人资料”均提供“退出登录”。确认后立即清空本机登录状态、个人资料缓存和页面栈，同时向服务器撤销当前凭证。旧凭证不能再读取私有资料或提交业务；公开浏览按游客处理。资料加载失败时仍可退出。

退出后刷新页面、切换页面或重启小程序均保持未登录，必须主动点击微信登录。云端账号及原有资料不会因为退出而删除。

离线时先完成本机退出，持久保存待撤销凭证；下次启动或回到前台重试撤销。服务器只能在收到请求后完成撤销。新登录会换发凭证，迟到的旧退出请求不能撤销新会话。

## 注销账户

- 申请时在服务端事务内检查本应用该微信身份在**全部学校／校区**的发单和接单。仅完成（9）和取消（99）视为终态；待接单、履约中、异常处理等未完成状态均阻止注销。旧数据和被后台隐藏但未结束的订单同样检查。
- 注销成功立即退出，从服务端记录的 `requestedAt` 起保留 **2 小时**撤销期。重复提交同一申请不延长截止时间。
- 只有用户主动微信登录，并且服务端时间严格早于 `cancelAt`，才自动取消注销并保留原资料。打开小程序、静默刷新、游客访问、失败的身份登录不能撤销。时间**等于截止时间**即视为到期。
- 到期后先禁用恢复和业务写入，再分批清理。新 `ordersWorker` 的每分钟维护负责执行，不要求用户再次打开小程序。到期登录也会尝试续跑清理；未完成时提示稍后再登录。
- 数据库或存储暂时失败时保留注销状态和清理进度，下轮继续，不能因失败恢复旧账号。实际物理清理完成时间受下一次任务执行与重试影响，但超过两小时已不能取消注销。
- 清理完成后再登录建立全新资料，不恢复旧手机号、联系人、地址、收藏、通知、邀请码或旧订单所有权。

学校／校区被停用后仍可退出或申请注销。会话文档同时参与业务写入事务，注销与新发单／接单发生冲突时只允许一方成功。

个人资料、各校手机号绑定、收藏、通知、订阅、已读摘要、配额和客服消息会删除。已完成订单、评价、反馈及他人的邀请历史保留必要记录，但移除注销用户的身份、联系方式、私有文字与凭证副本；不会删除另一方的账号。

## 私有文件与历史数据边界

新头像和订单原图使用 `private/<openid>/<mediaGeneration>/`；服务端证据归档使用 `private-evidence/<openid>/<mediaGeneration>/`。普通退出、重新登录及两小时内恢复保留目录；注销完成后新注册使用新目录，旧清理不会碰到新账户的同内容图片。

已送到服务端的原图在下载／审核前登记，头像在资料内容审核前登记；审核拒绝也能在注销时发现。被替换的已登记图片仍保留清理索引。删除来源记录时，在同一事务内保存文件清单，成功删除后才移除清理日志；部分失败和“文件已不存在”可重试。

自动删除仅限配置的目标云环境、可确认本人 `private/` 或 `private-evidence/` 路径的文件。历史 `crun/user/...` 随机共享头像路径无法从现有数据证明所有者，代码仅移除引用；需按存储所有者元数据另行核对，不能删除用户随意提交的 URL。从未送到服务器的孤立上传也无法通过数据库枚举，应单独设置经核对的存储清理策略。

本功能不执行历史账号批量删除。已经单独完成的旧账号清理无需重做，正在测试的新账号也无需清空。

## 接口、凭证与配置

| 接口 | 行为 |
| --- | --- |
| `passport/wechat_identity_login` | 主动身份登录，返回 `{ token, user, cancellationCancelled }`；`token.sessionToken` 为新的随机会话凭证 |
| `passport/login` | 只刷新有效会话，不建号、不续期凭证、不撤销注销；无有效会话返回空 token |
| `passport/my_detail` | 有效会话下读取当前学校资料 |
| `passport/wechat_profile` | 单独保存头像昵称，不改变联系资料完成状态或审核结果 |
| `passport/register`、`passport/edit_base` | 补全／编辑当前微信账号资料 |
| `passport/logout` | 撤销所提交凭证；不依赖可用校区 |
| `passport/cancel` | 检查全部未完成订单，申请两小时注销并撤销会话 |
| `operations/config` | 公开业务配置；已登录时返回当前账户上传目录 |

身份只来自云函数可信 `OPENID`，不接受客户端指定账号。数据库只保存会话摘要；普通会话有效期为 24 小时，主动登录轮换凭证，退出／注销立即使该凭证失效。同校跨校区共享资料，不同学校资料仍隔离；会话和注销范围覆盖本应用该微信身份。

| 配置 | 行为 |
| --- | --- |
| `WECHAT_PHONE_LOGIN_ENABLED` 未设置或 `false` | 默认头像昵称＋微信身份登录，隐藏并停用手机号兑换 |
| `WECHAT_PHONE_LOGIN_ENABLED=true` | 显式启用保留的旧手机号授权流程，需对应平台能力 |
| `ALLOW_MANUAL_REGISTRATION` | 兼容旧手机号模式的手填联系电话策略；不会开放游客手动建号。基础模式始终允许手填联系资料 |

## 配套部署

1. 核对 AppID、目标云环境和体验成员，设置 `CLOUD_ENV_ID`，保持默认手机号模式关闭。
2. 上传最新 `cloudfunctions/mcloud` 并云端安装依赖。初始化标记为 `bx_setup_crun_20260923_accounts`，必须由代码在集合就绪后创建。
3. 为 `bx_account_session`、`bx_account_media`、`bx_account_cleanup_file` 及全部业务集合设置客户端 `read=false/write=false`。按 [索引清单](database-indexes.json) 核验账户到期、跨校身份和文件日志查询；清理日志不能用 TTL 提前删除。
4. 从当前源码重新生成并部署 `ordersWorker` 等配套函数，确认每分钟触发器有效。API 与存储调用设置有界超时（建议 API 30 秒、worker 60 秒），最长在途写入必须短于两小时撤销期。生成和校验命令见 [部署手册](MULTI_TENANT_ROLLOUT.md)。
5. 重新编译客户端并生成新真机预览。旧客户端及旧 token 不含服务端凭证，必须主动重新登录，不能按旧 OPENID 静默恢复。不要只更新前端或继续使用旧 worker 快照。

更新本功能不需要清空账户或重复学校迁移。客户端和管理界面已统一为“GXNU校跑”；微信搜索／分享使用的注册名称仍需在公众平台核对和修改，项目配置不会自动重命名平台账号。

## 真机验收

| 场景 | 预期 |
| --- | --- |
| 点击“点击微信登录” | 同一弹层显示头像和昵称；取消时不登录 |
| 选择两项并确认 | 保存最终昵称头像，自动进入个人资料；联系资料一直展开 |
| 身份成功但图片上传／资料保存失败 | 保留选择，重试成功后进入个人资料，不重复身份登录 |
| 退出后刷新、重启或收到旧请求回包 | 保持游客，不能恢复个人资料或继续旧提交 |
| 离线退出后恢复网络 | 本机一直未登录，前台补发服务端撤销 |
| 有未完成发单／接单，包括其他学校 | 拒绝注销并保留登录 |
| 申请注销后两小时内主动登录 | 提示已取消注销，保留原资料 |
| 注销期仅打开小程序、静默刷新 | 不取消注销 |
| 正好两小时、到期任务、清理失败重试 | 旧账号不可恢复；完成清理后再登录为新账号 |
| 审核拒绝的图片、曾替换图片 | 其已登记的本人私有文件也纳入注销清理 |
| 同身份直接重新登录、旧上传稍后完成 | 旧请求不覆盖新会话资料 |

## 保留的手机号流程排错

以下仅适用于显式开启旧手机号模式。默认模式不应弹出手机号授权或调用 `phonenumber.getPhoneNumber`。

| 诊断 | 处理 |
| --- | --- |
| `cancelled` | 用户取消，可再次主动授权 |
| `privacy`、`permission_denied`／102 | 按对应 AppID 核对微信隐私声明和手机号服务权限 |
| `unsupported`、`unavailable` | 检查微信客户端或平台服务状态 |
| `missing_code`、`native_error` | 未取得有效授权结果，重新主动授权 |
| `environment_missing`、`function_missing`、`timeout` | 分别核对云环境、最新 mcloud 部署和网络耗时 |
| `phone_exchange_failure` | 按数值错误码核对能力和一次性 code，不自动重放 code |

`private_getBackgroundFetchData:fail` 是另一个微信内部接口，不能单独据此判断登录失败。诊断不记录手机号、一次性 code、token、微信身份或完整 SDK 错误。开启手机号模式时仍检查 AppID 水印和中国大陆号码，不在前端保存 AppSecret。
