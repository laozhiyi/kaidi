# 注册与后台保存的文字检查修复

更新：2026-09-22。本次已完成本地修改和自动化核验，尚未上传云函数或执行真机验收。

手填注册后续提示“微信文字审核服务暂不可用”的代码原因也已定位：`framework/cloud/cloud_base.js` 把 SDK 的可调用 `openapi` 命名空间当普通函数执行 `.bind()`，SDK 因而误发名为 `bind` 的请求，审核方法无法访问。现在原样保留这个命名空间；数据库隔离和普通 SDK 方法绑定继续生效。此前测试分别覆盖业务和 SDK，遗漏了二者之间的生产封装；本轮用实际封装与 SDK 复现原提示，并把这一组合纳入全量回归。

旧实现把微信接口异常、权限不足、异常回包和实际审核拒绝统一显示为“文字内容不合适，请修改或者重试”。注册提交的手机号、头像文件标识、表单结构，以及后台的整份配置也被拼成文字送审。因此，旧提示本身无法证明哪个字段违规，也不能证明内容确实被微信拒绝。

## 保存行为

| 入口 | 本次处理 |
| --- | --- |
| 注册、个人资料编辑 | 先检查必填项和格式，再按资料场景分别审核昵称、学院、专业、联系人姓名和地址文字；正常的手机号、图片标识与选择项不作为自由文字送审 |
| 旧版补充资料 | 仍检查实际文字；使用服务端字段名称或条目序号说明位置。重复显示名称不会覆盖其他待审字段，客户端修改字段 type 不能跳过已知文本项 |
| 营业、履约规则、价格数字设置 | 先校验分组、类型和范围；只有新增或修改的文字需要调用审核。价格页面带上的原结算说明不重复送审 |
| 修改结算说明 | 审核规范化后将保存的说明；通过后才进入保存事务。拒绝或服务异常时保留原配置与页面草稿 |

注册和配置使用逐字段检查；其他既有提交继续使用批量检查。长文字分段保留完整 Unicode 字符。审核服务默认启用，注册审核政策、账号身份、后台角色和数据范围继续由各自服务验证。

## 提示与排查

| 返回情况 | 新提示与处理 |
| --- | --- |
| 微信返回 `risky` 或 `87014` | 指出具体字段，例如“「学院」未通过微信文字审核，请修改该字段后重试”。微信没有提供具体词语时，页面不猜测哪一个词违规 |
| 微信返回 `review` | 明确提示对应字段“被微信标记为需复核”，当前提交不会自动通过 |
| `48001`、`48002` | 显示文字审核服务调用权限问题及数值错误码，检查目标 AppID、云函数 OpenAPI 权限和服务状态 |
| `40003` 或缺少可信微信身份 | 显示文字审核身份校验问题，重新进入小程序后重试；不要传入客户端提供的 OPENID 代替云端身份 |
| `45009`、`45011`、超时 | 显示服务繁忙或超时，可稍后重试 |
| 缺少结果、未知状态或其他接口异常 | 显示审核服务异常；未知结果不视为通过，也不标成文字违规 |

云端新增 `[text-audit]` 诊断，仅包含固定 `reason` 与数值 `errCode`，不记录提交文字、手机号、令牌或接口原始错误。手机号授权的原生 `102` 和后台预拉取日志与这项检查属于不同接口。

## 更新到真机

1. 在微信开发者工具选择本项目正在调用的云环境。
2. 右键 `cloudfunctions/mcloud`，选择“上传并部署：云端安装依赖”，等待成功。本次须包含更新后的 `framework/cloud/cloud_base.js`；仅有上一轮 `content_check.js` 的错误提示修复仍会失败。`config.json` 已包含 `security.msgSecCheck`；须确认这份配置随函数实际部署。只重新编译小程序不会更新云端检查代码。
3. 重新编译并进入小程序，测试普通资料注册，以及营业开关、价格数值、结算说明的分别保存。若仍出现服务权限错误，按新提示的错误码检查云端服务；当前没有真实微信返回码，不能预先断定线上缺哪项权限。

API 源码位于 `cloudfunctions/mcloud`。配套 worker 应按 [多校部署与迁移手册](MULTI_TENANT_ROLLOUT.md) 从当前源码重新构建并校验，不能复用历史快照；worker 包不能代替 API 源目录上传。

## 本地复核

在项目根目录运行：

```powershell
npm.cmd test --prefix cloudfunctions/mcloud
node scripts/check-content-audit-sdk.cjs
node scripts/check-architecture-source.cjs
```

全量测试包含 `content-audit.test.js` 和 `cloud-sdk-wrapper.test.js`，覆盖真实注册／配置路由、实际价格页、字段选择、拒绝与服务故障不落库，以及生产云封装和 SDK 的组合。SDK 脚本检查命名空间选项、v2 回包和错误分类，请求在本地传输边界被拦截，不会访问微信。

检查结果以当前源码和当次输出为准；本地通过不替代部署后的平台权限、额度和真机验收。
