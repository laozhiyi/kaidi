# 文字与图片内容审核

注册、个人资料和后台设置保存时调用微信内容安全接口。审核逻辑在 `framework/validate/content_check.js`，OpenAPI 调用经过 `framework/cloud/cloud_base.js` 的生产云封装。该封装必须原样保留 SDK 的 `openapi` 命名空间，不能对它执行 `.bind()`，否则 SDK 会发出名为 `bind` 的错误请求，审核方法无法访问。

## 送审范围

| 入口 | 处理 |
| --- | --- |
| 注册、个人资料编辑 | 先检查必填项和格式，再逐字段审核昵称、学院、专业、联系人姓名和地址文字；手机号、图片标识与选择项不作为自由文字送审 |
| 旧版补充资料 | 检查实际文字，用服务端字段名称或条目序号说明位置。重复显示名称不会覆盖其他待审字段，客户端修改字段 type 不能跳过已知文本项 |
| 营业、履约规则、价格数字设置 | 先校验分组、类型和范围；只有新增或修改的文字需要审核。价格页带上的未修改结算说明不重复送审 |
| 修改结算说明 | 审核规范化后将保存的说明，通过后才进入保存事务；拒绝或服务异常时保留原配置与页面草稿 |

注册和配置使用逐字段检查，其他提交使用批量检查。长文字分段时保留完整 Unicode 字符。审核默认启用；注册审核政策、账号身份、后台角色和数据范围由各自服务验证。

## 返回情况与提示

| 返回情况 | 提示与处理 |
| --- | --- |
| `risky` 或 `87014` | 指出具体字段，例如「「学院」未通过微信文字审核，请修改该字段后重试」。微信不提供具体词语时，页面不猜测哪个词违规 |
| `review` | 提示对应字段「被微信标记为需复核」，当前提交不会自动通过 |
| `48001`、`48002` | 显示审核服务调用权限问题及错误码，检查目标 AppID、云函数 OpenAPI 权限和服务状态 |
| `40003` 或缺少可信微信身份 | 显示身份校验问题，重新进入小程序后重试；不要用客户端提供的 OPENID 代替云端身份 |
| `45009`、`45011`、超时 | 显示服务繁忙或超时，可稍后重试 |
| 缺少结果、未知状态或其他异常 | 显示审核服务异常；未知结果不视为通过，也不标成文字违规 |

云端日志的 `[text-audit]` 诊断只包含固定 `reason` 与数值 `errCode`，不记录提交文字、手机号、令牌或接口原始错误。手机号授权的原生 `102` 错误属于另一个接口，见 [登录与账户](WECHAT_LOGIN.md#资料页手机号验证排错)。

## 图片检查

客户端图片检查 `content_check_helper.imgCheck` 使用服务市场「图片内容安全」，返回三态：`true` 通过；`false` 仅表示明确拦截；`null` 表示检查不可用（未订阅服务、余额不足、返回为空或异常）。调用方只对 `false` 拦截，`null` 放行并 `console.warn` 留痕。`img_upload_cmpt` 同样只认 `check === false`。不要把服务不可用当成「图片不合适」。

## 部署

1. `mcloud/config.json` 需包含 `security.msgSecCheck` 权限，并随函数实际部署。
2. 在微信开发者工具选择目标云环境，右键 `cloudfunctions/mcloud` →「上传并部署：云端安装依赖」。只重新编译小程序不会更新云端审核代码。
3. 在真机分别测试资料注册，以及营业开关、价格数值、结算说明的保存。出现服务权限错误时，按提示的错误码检查云端服务。

## 本地检查

```powershell
npm.cmd test --prefix cloudfunctions/mcloud
node scripts/check-content-audit-sdk.cjs
```

全量测试中的 `content-audit.test.js` 和 `cloud-sdk-wrapper.test.js` 覆盖注册/配置路由、价格页、字段选择、拒绝与服务故障不落库，以及生产云封装和 SDK 的组合。SDK 脚本在本地传输边界拦截请求，不会访问微信；本地通过不代替部署后的平台权限、额度和真机验收。
