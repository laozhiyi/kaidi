# 云速取：微信登录、退出与账户注销

AppID 和基础库以 [项目配置](../project.config.json) 为准。

## 登录与个人资料

1. 打开登录页只显示登录入口，不自动创建账号、恢复资料或撤销注销。
2. 点击「点击微信登录」，云端使用可信微信身份创建或恢复账号，并返回会话。资料完整且联系电话已验证的用户返回「我的」或原业务页。资料未完成或手机号未验证的用户进入「个人资料」。
3. 在个人资料页通过原生控件选择头像、填写昵称，然后点「获取微信手机号」。授权成功后在当前页显示号码和「已验证」。更换号码需要重新授权。取消或失败时可以继续编辑资料并再次授权。
4. 个人资料中的联系资料始终展开，没有“收起／编辑联系资料”按钮。页面统一用“保存资料”，下方可退出登录或注销账户。新账号即使尚未补齐联系资料，也可进入“我的”管理账号。

微信目前不支持通过旧式的一次授权弹窗自动读取真实头像和昵称。这里使用官方原生填写控件：头像由用户选择，昵称输入时可使用微信昵称候选。保存读取 form 提交的最终昵称，不能用旧输入缓存覆盖。控件不可用时保留普通输入、相册／相机选择。官方规则见 [获取头像昵称](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/userProfile.html)，最终原生行为须在真机验证。

身份登录成功、头像上传或保存失败时，弹层保留已选资料并显示错误；主动重试复用当前有效身份会话，不重复建号。退出、重新登录或会话失效后，旧资料请求、上传回包和业务自动重试不能写入新会话。

联系电话由云端保存微信返回的号码。所有资料保存入口检查当前账号的验证状态和号码，新注册还统一检查学号和学生证。用户服务协议及隐私政策按版本在资料页显式确认，历史免责声明布尔值不作为新版同意。云端校验 `agreements.accepted/userVersion/privacyVersion`，用服务端时间保存 `USER_AGREEMENTS` 及 `USER_AGREEMENT_HISTORY`；已同意当前版本的普通资料修改保留原同意时间，不重复确认。历史手填号码需要补验，可以由真正授权该号码的同校用户取得绑定。其他账号已验证的号码继续受到同校唯一性保护。新版学生证须从当前账号的私有目录上传，经服务端校验并归档。已审核通过的新版学号和证件通过反馈投诉申请更正。历史资料可重新上传证件，变更后重新进入审核。

用户、骑手、隐私和实名信息说明统一存放在 `public/agreements.js`，通过独立协议页展示重点条款，设置页长期提供入口；版本须与云端 `public/agreement_versions.js` 同步发布。首次不预勾选；点击正文链接不改变同意状态。登录页只提供阅读入口，不使用“登录即同意”代替注册时确认。旧用户在“我的”看到新版提示，可进入个人资料阅读确认；云端对新发单、新接单在事务中校验当前同意记录，不妨碍已有订单履约、取消退款和反馈，也不阻断旧请求的幂等结果核对。

`passport/my_detail` 的数据库字段选择必须包含 `USER_AGREEMENTS`，与登录令牌中的 `agreements` 保持一致。资料页以该版本化记录恢复勾选状态，不能用旧免责声明字段代替；读取个人资料不下发完整同意历史。保存后重新进入的回归测试必须启用字段筛选，避免测试中的完整用户对象掩盖接口漏字段。

订单列表和订单详情的接单入口在确认接单及提交命令前检查用户协议。登录缓存缺少当前版本的同意记录时，先查询 `passport/my_detail` 核对已保存的记录；未同意则提示“去确认协议 / 暂不处理”，前往个人资料并定位到协议区域。已开通结算但骑手协议过期时，使用相同引导前往结算页的协议区域。查询失败、响应不完整、账号或校区变化时停止接单，不将系统异常当成未同意协议；云端事务仍保留最终校验。个人资料首次加载失败后重试成功，也会继续执行尚未完成的协议定位。

资料页取消勾选但未保存，只影响当前表单，不撤销服务端已保存的同意记录。该账号仍按已有有效记录检查接单资格。订单列表和详情在用户确认接单后均显示带遮罩的“接单中，请稍候”，请求结束先关闭加载再展示结果；结果不确定时保留原请求标识并提供“核对上次”，不把超时当成已接单或重新创建接单命令。取消确认不发出接单请求，重复点击只执行一条命令。

点击接单后，在登录、协议与结算核验期间显示“正在检查接单资格”，不等到提交接单时才提供反馈。交互触发的登录状态核验失败时显示具体错误，静默刷新失败则不弹窗；页面离开后不展示旧请求的提示。开发者工具 Console 的 `[order-accept]` 阶段日志只记录入口、阶段和页面可见状态，不包含用户信息或订单凭证。

个人资料及完整注册表单允许点击保存进行校验；未勾选协议或必填项不完整时，页面滚动到首个问题区域，以红框和就近文字说明原因，并在上传头像或证件前拦截。接单或发单因协议版本失效受阻时，可选择“去确认协议”进入个人资料，直接定位到协议区域；原页面及草稿保留，返回后由用户主动继续操作，不自动接单、提交或付款。已有当前版本同意记录的用户默认显示已同意，主动取消勾选后同样不能保存该表单。云端拒绝显式不同意、空确认对象或版本不匹配的请求，不用历史同意覆盖本次明确选择；没有重新提交协议字段的独立资料编辑仍可沿用有效记录，并保留原同意时间。

**待审核（`USER_STATUS=0`）账号资料完整且手机号验证后即可发单，接单要求审核通过（`USER_STATUS=1`）**。审核拒绝和停用账号均不能发单或接单。文字检查说明见 [内容审核](CONTENT_AUDIT.md)。

独立手动注册和授权失败后自动转手动注册已移除；资料表单只能更新通过微信登录建立的账号，不能给游客建号。

## 退出登录

“我的”和“个人资料”均提供“退出登录”。确认后立即清空本机登录状态、个人资料缓存和页面栈，同时向服务器撤销当前凭证。旧凭证不能再读取私有资料或提交业务；公开浏览按游客处理。资料加载失败时仍可退出。

退出后刷新页面、切换页面或重启小程序均保持未登录，必须主动点击微信登录。云端账号及原有资料不会因为退出而删除。

离线时先完成本机退出，持久保存待撤销凭证；下次启动或回到前台重试撤销。服务器只能在收到请求后完成撤销。新登录会换发凭证，迟到的旧退出请求不能撤销新会话。

## 注销账户

- 申请时在服务端事务内检查本应用该微信身份在**全部学校／校区**的发单和接单。仅完成（9）和取消（99）视为终态；待接单、履约中、异常处理等未完成状态均阻止注销。旧数据和被后台隐藏但未结束的订单同样检查。
- 注销成功立即退出，从服务端记录的 `requestedAt` 起保留 **2 小时**撤销期。重复提交同一申请不延长截止时间。
- 只有用户主动微信登录，并且服务端时间严格早于 `cancelAt`，才自动取消注销并保留原资料。打开小程序、静默刷新、游客访问、失败的身份登录不能撤销。时间**等于截止时间**即视为到期。
- 到期后先禁用恢复和业务写入，再分批清理。新 `mcloud` 的每分钟定时维护负责执行，不要求用户再次打开小程序。到期登录也会尝试续跑清理；未完成时提示稍后再登录。
- 数据库或存储暂时失败时保留注销状态和清理进度，下轮继续，不能因失败恢复旧账号。实际物理清理完成时间受下一次任务执行与重试影响，但超过两小时已不能取消注销。
- 清理完成后再登录建立全新资料，不恢复旧手机号、联系人、地址、收藏、通知、邀请码或旧订单所有权。

学校／校区被停用后仍可退出或申请注销。会话文档同时参与业务写入事务，注销与新发单／接单发生冲突时只允许一方成功。

个人资料、各校手机号绑定、收藏、通知、订阅、已读摘要、配额和客服消息会删除。已完成订单、评价、反馈及他人的邀请历史保留必要记录，但移除注销用户的身份、联系方式、私有文字与凭证副本；不会删除另一方的账号。

## 私有文件与历史数据边界

新头像和订单原图使用 `private/<openid>/<mediaGeneration>/`；服务端证据归档使用 `private-evidence/<openid>/<mediaGeneration>/`。普通退出、重新登录及两小时内恢复保留目录；注销完成后新注册使用新目录，旧清理不会碰到新账户的同内容图片。

已送到服务端的原图在下载／审核前登记，头像在资料内容审核前登记；审核拒绝也能在注销时发现。被替换的已登记图片仍保留清理索引。删除来源记录时，在同一事务内保存文件清单，成功删除后才移除清理日志；部分失败和“文件已不存在”可重试。

自动删除仅限配置的目标云环境、可确认本人 `private/` 或 `private-evidence/` 路径的文件。历史 `crun/user/...` 随机共享头像路径无法从现有数据证明所有者，代码仅移除引用；需按存储所有者元数据另行核对，不能删除用户随意提交的 URL。从未送到服务器的孤立上传也无法通过数据库枚举，应单独设置经核对的存储清理策略。

本功能不执行历史账号批量删除。

## 接口、凭证与配置

| 接口 | 行为 |
| --- | --- |
| `passport/wechat_identity_login` | 主动身份登录，返回 `{ token, user, cancellationCancelled }`；`token.sessionToken` 为新的随机会话凭证 |
| `passport/login` | 只刷新有效会话，不建号、不续期凭证、不撤销注销；无有效会话返回空 token |
| `passport/my_detail` | 有效会话下读取当前学校资料 |
| `passport/wechat_profile` | 单独保存头像昵称，不改变联系资料完成状态或审核结果 |
| `passport/verify_profile_phone` | 使用有效会话绑定微信授权号码，并用同一会话返回最新验证状态 |
| `passport/register`、`passport/edit_base` | 补全／编辑当前微信账号资料 |
| `passport/logout` | 撤销所提交凭证；不依赖可用校区 |
| `passport/cancel` | 检查全部未完成订单，申请两小时注销并撤销会话 |
| `operations/config` | 公开业务配置；已登录时返回当前账户上传目录 |

身份只来自云函数可信 `OPENID`，不接受客户端指定账号。数据库只保存会话摘要；普通会话有效期为 24 小时，主动登录轮换凭证，退出／注销立即使该凭证失效。同校跨校区共享资料，不同学校资料仍隔离；会话和注销范围覆盖本应用该微信身份。

资料页强制验证手机号。资料页强制验证时，旧环境变量 `WECHAT_PHONE_LOGIN_ENABLED` 和 `ALLOW_MANUAL_REGISTRATION` 不生效（见 `service/profile_rules.js`），可从云端配置移除。

## 配套部署

1. 核对 AppID、目标云环境和体验成员，设置 `CLOUD_ENV_ID`。确认该 AppID 已开通手机号快速验证、有可用额度，并在隐私保护指引中声明手机号用途。
2. 上传最新 `cloudfunctions/mcloud` 并云端安装依赖。初始化标记由代码在集合就绪后创建，不要手工提前创建。
3. 为 `bx_account_session`、`bx_account_media`、`bx_account_cleanup_file` 及全部业务集合设置客户端 `read=false/write=false`。按 [索引清单](../deployment/database-indexes.json) 建立 `bx_user` 的 `school_verified_phone` 复合索引并核验其他账户索引。云存储须允许本人上传 `private/`，并禁止客户端写入 `private-evidence/`，详见 [部署手册](DEPLOYMENT.md)。
4. 从当前源码重新上传 `mcloud`（定时任务已内置在 `config.json` 的两个每分钟触发器里），确认控制台里触发器有效。API 与存储调用设置有界超时（建议 API 30 秒、定时分支预算 20 秒），最长在途写入必须短于两小时撤销期。生成和校验命令见 [部署手册](DEPLOYMENT.md)。
5. 重新编译客户端并生成新真机预览。旧客户端及旧 token 不含服务端凭证，必须主动重新登录，不能按旧 OPENID 静默恢复。不要只更新前端或继续使用旧 worker 快照。

更新本功能不需要清空账户或重复学校迁移。客户端和管理界面统一显示“云速取”；微信搜索／分享使用的注册名称仍需在公众平台核对和修改，项目配置不会自动重命名平台账号。

## 真机验收

| 场景 | 预期 |
| --- | --- |
| 点击「点击微信登录」 | 需要补资料或补验号码的账号进入个人资料，资料完整且已验证的账号返回原入口 |
| 获取微信手机号 | 在当前资料页完成授权并回填号码，保存后重新打开仍显示已验证 |
| 取消授权或更换号码失败 | 停留在资料页，保留当前号码和表单草稿 |
| 用未验证号码提交资料 | 云端拒绝保存。已有手填号码的用户可以登录后补验 |
| 身份成功但图片上传／资料保存失败 | 保留选择，重试成功后按资料是否完整决定去向，不重复身份登录 |
| 退出后刷新、重启或收到旧请求回包 | 保持游客，不能恢复个人资料或继续旧提交 |
| 离线退出后恢复网络 | 本机一直未登录，前台补发服务端撤销 |
| 有未完成发单／接单，包括其他学校 | 拒绝注销并保留登录 |
| 待审核账号资料完整后发单 | 允许；尝试接单时提示需审核通过 |
| 申请注销后两小时内主动登录 | 提示已取消注销，保留原资料 |
| 注销期仅打开小程序、静默刷新 | 不取消注销 |
| 正好两小时、到期任务、清理失败重试 | 旧账号不可恢复；完成清理后再登录为新账号 |
| 审核拒绝的图片、曾替换图片 | 其已登记的本人私有文件也纳入注销清理 |
| 同身份直接重新登录、旧上传稍后完成 | 旧请求不覆盖新会话资料 |

## 资料页手机号验证排错

| 诊断 | 处理 |
| --- | --- |
| `cancelled` | 用户取消，可再次主动授权 |
| `privacy`、`permission_denied`／102 | 按对应 AppID 核对微信隐私声明和手机号服务权限 |
| `unsupported`、`unavailable` | 检查微信客户端或平台服务状态 |
| `missing_code`、`native_error` | 未取得有效授权结果，重新主动授权 |
| `environment_missing`、`function_missing`、`timeout` | 分别核对云环境、最新 mcloud 部署和网络耗时 |
| `phone_exchange_failure` | 按数值错误码核对能力和一次性 code，不自动重放 code |

云端检查授权结果的 AppID 水印和中国大陆号码。诊断只使用错误分类和数值错误码，避免输出手机号、授权码和会话凭证。
